# ReactÖğren – Sıfırdan React ve TSX Eğitimi

## Proje Hakkında
ReactÖğren, modern web geliştirme standartlarına uygun, tamamen React ve TypeScript ile hazırlanmış interaktif bir eğitim platformudur. Fonksiyonel bileşenler, tip güvenliği, state yönetimi, router, formlar ve daha fazlası gerçek kod örnekleriyle anlatılır.

## Özellikler
- Fonksiyonel ve modüler React bileşenleri
- TypeScript ile tam tip güvenliği
- TailwindCSS ile modern ve responsive tasarım
- Kod blokları ve canlı demolar
- React Router ile sayfa geçişleri
- Form yönetimi ve validasyon örnekleri
- Temiz ve anlaşılır dosya yapısı

## Kurulum ve Çalıştırma
1. Bağımlılıkları yükleyin:
   ```bash
   npm install
   ```
2. Geliştirme sunucusunu başlatın:
   ```bash
   npm start
   ```
3. Tarayıcıda [http://localhost:5173](http://localhost:5173) adresini açın.

## Klasör Yapısı
```
src/
  components/    # Ortak ve özel React bileşenleri
  data/          # Konu ve içerik verileri
  layouts/       # Sayfa düzenleri
  pages/         # Sayfa bileşenleri
  types/         # TypeScript tipleri
  assets/        # Görseller ve statik dosyalar
```
